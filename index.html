The chart nobody can fake and nobody can rush. Each dot is a confidence band: how sure the machine claimed to be, against how often it was actually right. On the diagonal means honest. How it works

Why this is hard to fake

01 · Observe

Six keyless public sources — crypto, geomagnetic storms, earthquakes, Wikipedia, Hacker News, the weather — read fresh each run.

02 · Predict

Each rule makes one binary call with a stated confidence, using only what was knowable at that moment.

03 · Commit

The calls are pushed before the outcome exists. The commit timestamp sits in public git history and cannot be moved.

04 · Grade

Grading is re-derived from the archive on every run, so the ledger is a pure function of the record — never an accumulated number that could drift.
